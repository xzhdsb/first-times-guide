# 人生第一次指南

给每个第一次遇到陌生生活场景的人，一张清楚、能照着走的路线图。

## 在线阅读

[打开 GitHub Pages 在线版](https://xzhdsb.github.io/first-times-guide/)。页面从仓库 `main` 分支根目录的 `index.html` 发布。

## 下载与离线阅读

打开页面后点击“下载离线版”，即可保存完整的独立 HTML 文件。它包含全部指南、样式和交互，断网后也能搜索和浏览。仓库中的 `index.html` 也是完整源文件，可直接下载后在浏览器打开。

## 第一版内容

- **出行与交通**：第一次坐飞机、第一次坐高铁、第一次坐地铁
- **餐饮与消费**：第一次喝星巴克、第一次去西餐厅
- **生活办事**：第一次租房、第一次去医院看病
- **职场与社会**：第一次去银行办业务、第一次做入职体检、第一次签劳动合同

## 内容维护

所有页面、样式、交互和指南都维护在 `index.html`。新增指南时，在页面脚本的 `GUIDES` 列表中增加一条记录，并按现有结构填写分类、摘要、准备事项、步骤、话术、注意事项、来源和核实日期。

规则类内容优先链接政府部门、服务运营方或机构的一手来源，并更新核实日期。不同城市、机构、航司或门店的做法要明确说明适用范围。没有统一硬性规则的礼仪与经验内容标为经验整理。就医指南只讲办事流程，不替代诊断与治疗建议。

## 发布

本仓库通过 GitHub Pages 从 `main` 分支的根目录发布。修改 `index.html` 并推送到 `main` 后，Pages 会自动更新。
